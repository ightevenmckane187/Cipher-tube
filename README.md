# Cypher-Tube OS v1.0

Cypher-Tube is a sovereign, governed, transactional, multi-agent operating system. It treats agentic labor as a first-class operational concern, prioritizing safety, durability, and human oversight.

## Core Architectural Pillars
- **Kernel:** `BrainCore` orchestrates logic with a built-in circuit breaker.
- **Ethics:** Role-based guardrails ensure agents operate within their bounds.
- **Governance:** Persistent HIL (Human-in-the-Loop) oversight for sensitive operations.
- **Resilience:** SAGA-based transactional rollbacks for all destructive actions.
- **Coordination:** Ticket-based handoff for multi-agent collaboration.
- **Meta-Cognition:** A reflective layer that analyzes telemetry to suggest system improvements.

## Control Plane
The dashboard acts as the administrative command center, featuring:
- **Live Trace:** Real-time observability of every OS event.
- **Ticket Pipeline:** A Kanban-style view of workforce tasks.
- **Emergency Halt:** A global circuit breaker for safe system suspension.
- **Operator Console:** An in-app, context-aware runbook.

## Quick Start
1. **Backend:** `pip install -r requirements.txt && python app/main.py`
2. **Frontend:** `cd web && npm install && npm run dev`
3. **Control:** Access the Dashboard at `http://localhost:3000`
