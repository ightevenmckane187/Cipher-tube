# Myth-Physics Engine (MPE) Specification

## Core Principles
The MPE defines the localized rules of reality within a given state tier.

### Localized Rules
- Entropy Boundaries: Defines the hard limits of decay and order.
- Paradox Exceptions: Allows for localized violations of standard logic when sanctioned by the Paradox-Field Engine.

### Constants
- `mp_constants`: A set of variables that define the physical properties of the current environment.
