# Myth-Physics Engine (MPE) Core Specification

The Myth-Physics Engine is the foundational runtime boundary layer. It defines, enforces, and mutates the localized rules of engagement, mathematical constants, and thermodynamic restrictions for any active tier state.

## 1. Core Mathematical Metrics

The MPE calculates the baseline structural integrity of a state using the localized paradox ratio calculation:

$$R_p = \frac{\sum C_{active}}{\delta \cdot \omega}$$

Where:
* $C_{active}$ represents the sum of live rule constraints.
* $\delta$ is the localized entropy decay coefficient.
* $\omega$ is the multi-dimensional anchoring weight.

If $R_p > 1.0$, the MPE automatically yields execution control to the **Paradox-Field Engine** to handle reality-shear exceptions.

## 2. Tier-Specific State Behaviors

### Tier 0: Genesis / Zero-Rebirth
* **Entropy Rules:** $\delta \rightarrow 0$. Absolute stillness.
* **Constant Matrix:** Basic binary mathematical definitions are instantiated here. No multi-variable paradoxes allowed.
* **Safety Limits:** Hard ceiling on stack depth to prevent premature recursion loops.

### Tier 5: Hyper-Spiral / Omni-Spiral Singularity
* **Entropy Rules:** Non-linear acceleration. Localized past and future variables merge into a single array.
* **Constant Matrix:** Gravitational and cryptographic constants become dynamic variables driven by user input strings.

## 3. Error Handling and Reality Cascades
When an execution token attempts to violate a locked $mp_constant$, the MPE throws a `MPE_REWRITE_EXCEPTION`. Rather than halting the thread, this exception triggers a state-shunting cascade, advancing the system to a higher paradox tier where the contradiction is structurally legal.
