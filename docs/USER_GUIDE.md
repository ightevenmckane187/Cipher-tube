# Cipher-Tube User Guide (Accessible)

## Welcome to Cipher-Tube

Cipher-Tube is a high-performance session management and cryptographic service. This guide provides instructions on how to use the platform effectively and accessibly.

## Getting Started

1. **Login:** Use your credentials to authenticate.
2. **Dashboard:** Overview of your active sessions and security status.
3. **Session Management:** Create, extend, or terminate sessions.

## Accessibility Features

- **Keyboard Shortcuts:**
  - `t`: Toggle Dark/Light mode.
  - `c`: Copy curl command to clipboard.
- **Skip Links:** Use the "Skip to content" link at the top of the page to jump directly to the main content.
- **Screen Readers:** All interactive elements have descriptive labels for use with screen readers like NVDA or VoiceOver.

## Managing Sessions

Sessions have a default duration of 60 minutes (3600 seconds).

- **Timeout Warnings:** You will receive a warning 60 seconds before your session expires.
- **Extending Sessions:** Select the "Extend Session" button in the warning dialog to reset your session timer.
