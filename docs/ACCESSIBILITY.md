# Accessibility Statement

Cipher-Tube is committed to ensuring digital accessibility for all users, including individuals with disabilities. We aim to conform to WCAG 2.1 Level AA and Section 508 of the Rehabilitation Act.

## Conformance Status

The Web Content Accessibility Guidelines (WCAG) defines requirements for designers and developers to improve accessibility for people with disabilities. Cipher-Tube is **substantially conformant** with WCAG 2.1 level AA.

## Key Accessibility Features

- **Keyboard Navigation:** Full support for keyboard-only interaction.
- **Semantic HTML:** Use of landmarks and proper heading structures.
- **Color Contrast:** High-contrast themes available and system-preference detection.
- **Reduced Motion:** Respects user's OS-level motion settings.

## Areas for Improvement

We are actively working on:

- Enhancing ARIA labeling for complex cryptographic components.
- Implementing session timeout warnings and extension controls.
- Providing documentation in multiple accessible formats.

## Feedback & Support

We welcome your feedback on the accessibility of Cipher-Tube. Please let us know if you encounter accessibility barriers:
